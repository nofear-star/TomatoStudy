# 番茄自习室后端 - 快速启动指南

## 📋 前置准备

### 1. 安装环境
- ✅ JDK 17+ 
- ✅ Maven 3.6+
- ✅ MySQL 8.0+

### 2. 创建数据库

登录MySQL，执行以下命令：

```sql
-- 创建数据库
CREATE DATABASE IF NOT EXISTS tomato_study_room DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

-- 使用数据库
USE tomato_study_room;
```

### 3. 导入表结构

在MySQL中执行SQL文件：
```bash
# Windows (在MySQL命令行中)
source E:/tomato/backend/src/main/resources/db/schema.sql

# 或者直接复制SQL内容到MySQL客户端执行
```

### 4. 导入初始数据（可选）

```bash
source E:/tomato/backend/src/main/resources/db/init-data.sql
```

## ⚙️ 配置数据库连接

编辑 `backend/src/main/resources/application.yml`：

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/tomato_study_room?useUnicode=true&characterEncoding=utf8&useSSL=false&serverTimezone=Asia/Shanghai&allowPublicKeyRetrieval=true
    username: root        # 修改为你的MySQL用户名
    password: 1939366582        # 修改为你的MySQL密码
```

## 🚀 启动项目

### 方式一：使用Maven命令

```bash
cd backend
mvn clean spring-boot:run
```

### 方式二：使用IDE

1. 使用IntelliJ IDEA或Eclipse打开项目
2. 找到 `StudyRoomApplication.java`
3. 右键 -> Run 'StudyRoomApplication'

### 方式三：打包后运行

```bash
cd backend
mvn clean package
java -jar target/study-room-backend-1.0.0.jar
```

## ✅ 验证启动

启动成功后，访问以下URL测试：

- 获取自习室列表: http://localhost:8080/api/rooms
- 获取背景音乐: http://localhost:8080/api/resources/background-music
- 获取系统配置: http://localhost:8080/api/system/configs

如果返回JSON数据，说明启动成功！

## 🐛 常见问题

### 问题1: 数据库连接失败
```
解决方案：
1. 确认MySQL服务已启动
2. 检查application.yml中的数据库配置
3. 确认数据库tomato已创建
```

### 问题2: 端口8080被占用
```
解决方案：
修改application.yml中的端口号
server:
  port: 8081  # 改为其他端口
```

### 问题3: 找不到主类
```
解决方案：
确认项目结构正确，主类路径为：
com.tomato.studyroom.StudyRoomApplication
```
