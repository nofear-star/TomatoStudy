# 番茄自习室后端项目说明

## 📋 项目概述

本项目是番茄自习室的后端服务，基于SpringBoot框架开发，提供完整的RESTful API接口。

## ✅ 已完成功能

### 1. 核心功能模块

#### 📚 自习室管理
- ✅ 获取自习室列表
- ✅ 创建自习室
- ✅ 获取单个自习室详情
- ✅ 更新自习室信息
- ✅ 解散自习室（限创建者）
- ✅ 加入自习室
- ✅ 离开自习室
- ✅ 获取自习室成员列表
- ✅ 踢出成员（限房主）

#### 📝 任务管理
- ✅ 获取当前用户的任务列表
- ✅ 创建新任务
- ✅ 更新任务信息
- ✅ 删除任务

#### 🎵 资源管理
- ✅ 获取背景音乐列表

#### ⚙️ 系统配置
- ✅ 获取系统配置信息

### 2. 技术架构

#### 分层架构
- **Controller层**: 处理HTTP请求，参数校验
- **Service层**: 业务逻辑处理
- **Mapper层**: 数据访问层（MyBatis Plus）
- **Entity层**: 数据库实体类
- **DTO层**: 数据传输对象

#### 核心技术
- Spring Boot 3.1.5
- MyBatis Plus 3.5.4
- MySQL 8.0+
- Lombok
- 统一响应格式
- 全局异常处理
- 跨域支持

### 3. 数据库设计

已创建11张数据表：
1. `user` - 用户表
2. `room` - 自习室表
3. `roommember` - 房间成员表
4. `tasks` - 任务表
5. `focussession` - 专注会话表
6. `backgroundmusic` - 背景音乐表
7. `system_configs` - 系统配置表
8. `studyreport` - 学习报告表
9. `friend` - 好友表
10. `friendrequest` - 好友请求表
11. `usercurrency` - 用户货币表
12. `userprivacy` - 用户隐私设置表

## 📡 API接口列表

### 基础URL
```
http://localhost:8080/api
```

### 接口清单

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/rooms` | 获取自习室列表 |
| POST | `/rooms` | 创建自习室 |
| GET | `/rooms/{roomId}` | 获取单个自习室 |
| PUT | `/rooms/{roomId}` | 更新自习室 |
| DELETE | `/rooms/{roomId}` | 解散自习室 |
| POST | `/rooms/{roomId}/join` | 加入自习室 |
| POST | `/rooms/{roomId}/leave` | 离开自习室 |
| GET | `/rooms/{roomId}/members` | 获取成员列表 |
| DELETE | `/rooms/{roomId}/members/{userId}` | 踢出成员 |
| GET | `/me/tasks` | 获取我的任务 |
| POST | `/tasks` | 创建任务 |
| PUT | `/tasks/{taskId}` | 更新任务 |
| DELETE | `/tasks/{taskId}` | 删除任务 |
| GET | `/resources/background-music` | 获取背景音乐 |
| GET | `/system/configs` | 获取系统配置 |

## 🔧 配置说明

### 数据库配置

配置文件位置: `src/main/resources/application.yml`

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/tomato
    username: root
    password: your_password
```

### 端口配置

默认端口: 8080

可通过 `application.yml` 修改：
```yaml
server:
  port: 8080
```

## 📦 项目文件说明

### 核心文件
- `StudyRoomApplication.java` - SpringBoot启动类
- `Result.java` - 统一响应格式
- `GlobalExceptionHandler.java` - 全局异常处理
- `CorsConfig.java` - 跨域配置

### 配置文件
- `application.yml` - 应用配置
- `pom.xml` - Maven依赖配置
- `schema.sql` - 数据库表结构
- `init-data.sql` - 初始化数据

## 🚀 快速启动

1. 创建数据库并导入SQL文件
2. 修改 `application.yml` 中的数据库配置
3. 运行 `StudyRoomApplication.java`
4. 访问 `http://localhost:8080/api/rooms` 测试

详细步骤请参考 `启动指南.md`

## 📝 统一响应格式

所有接口返回统一格式：

**成功响应**:
```json
{
  "code": 200,
  "message": "成功",
  "data": {}
}
```

**错误响应**:
```json
{
  "code": 500,
  "message": "错误信息",
  "data": null
}
```

## 🔒 权限说明

- 解散自习室: 仅创建者可执行
- 踢出成员: 仅房主可执行
- 更新/删除任务: 仅任务创建者可执行

## 📌 注意事项

1. 所有时间戳使用毫秒数（Long类型）
2. 任务状态枚举值: `未完成`, `进行中`, `已完成`
3. 房间成员状态: `active`, `left`, `kicked`
4. 数据库字段命名使用下划线，Java实体类使用驼峰命名
